## Found and fixed during the pass

- **Teaching pill covered the app's toolbar.** A tap on GitHub's search icon landed on the pill, so the teach recorded nothing. The pill is now one line inside the status bar while teaching.
- **Typed prefix + suggestion.** Replaying with a new value tapped the search bar (it holds the typed text) instead of a suggestion. The bar is no longer taken for a suggestion, and when no suggestion reads the value the search key is pressed instead.
- **Words around a value.** 'Repositories with "tensorflow"' tied with 'Code with "tensorflow"', so the model was needed; the words the demo had around the value now decide it.
- **Garlic bread.** With no dish named exactly "garlic bread", the match sitting where the demo's Margherita button had been won ("Korean Corn & Jalapeno Garlic Bread"). Now, among the dishes on screen, the one with the fewest other words wins, and screen position hardly counts for a named dish: "Classic Stuffed Garlic Bread". (Domino's here lists about fifteen garlic breads and no plain one.)
- **Myntra cross-app not always recognised.** The model sometimes said no taught flow fits "…on myntra … my bag"; an example in the prompt fixed it (3/3 after).
- **Apps that aren't installed, "in X".** Handled as above.
- **Wording.** "Which restaurant should I order from?" (was "should you"); task names drop the little word before a missing value; status replies read cleanly; "stop" during a question stops the run; placeholder words ("add an item") no longer become slots.
